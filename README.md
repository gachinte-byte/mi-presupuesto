# Mi Presupuesto

Aplicación web/PWA para llevar el presupuesto personal de forma sencilla y local.

## Características

- Presupuesto mensual: ingresos, gastos y extra disponible.
- Gastos organizados por categoría y subcategoría.
- Copiar gastos del mes anterior para evitar volver a digitarlos.
- Ingresos con opción de copiar el mes anterior.
- Ahorros e inversiones con actualización de saldos mensuales.
- Guardado local en el dispositivo mediante `localStorage`.
- Exportación e importación de datos en JSON para pasar la información a otro dispositivo.
- PWA preparada para instalarse en iPhone desde Safari.

## Publicar en GitHub Pages

1. Sube todos los archivos a la raíz del repositorio.
2. En GitHub entra a **Settings → Pages**.
3. Selecciona **Deploy from a branch**.
4. Selecciona `main` y `/ (root)`.
5. Guarda y abre la URL de GitHub Pages.

## Instalar en iPhone

Abre la URL publicada en **Safari** → botón **Compartir** → **Añadir a pantalla de inicio** → **Añadir**.

Los datos se guardan localmente en ese dispositivo. Para llevarlos a otro dispositivo usa **Configuración → Exportar datos a JSON** y luego **Importar JSON** en el otro dispositivo.
